# VEXcode

You will need to use [Chromium](https://wiki.archlinux.org/title/Chromium) or a Chromium-based browser
to use the VEXcode websites because they use the experimental WebUSB protocol.

This may be enough for you, but you might still get a popup telling you "VEXcode is not supported on Android".
In this case, you should install [an extension to spoof your User-Agent](https://chromewebstore.google.com/detail/user-agent-switcher-and-m/bhchdcejhohfmigjafbampogmaanbfkg) so that the page thinks you are running a different system.
